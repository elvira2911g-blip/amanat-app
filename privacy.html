Privacy Policy

Last updated: 2026-09-29

Amanat is a personal automation tool built and operated by a single individual for their own private use. It is not offered to the public and has exactly one user: its owner.

What data is accessed

With the owner's own Google account authorization, Amanat reads (read-only, via the gmail.readonly scope) email messages in the owner's own Gmail account — subject lines, message bodies, and attachments — in order to search for and summarize information the owner requests.

How data is used and stored

All processing happens locally on the owner's own computer. Email data is used only to answer the owner's own requests during a session. Data is not stored on any external server, not shared with any third party, and not used for advertising or any purpose other than the owner's own personal task automation.

Data sharing

No data collected through this access is sold, rented, or shared with third parties.

Revoking access

The owner can revoke this application's access at any time via Google Account → Security → Third-party apps with account access.
